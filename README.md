# NoteHub (Next.js)

Сучасний веб-додаток для створення, пошуку та зручного перегляду нотаток, розроблений на Next.js (App Router) із використанням TypeScript.

## 🚀 Основний функціонал

* **Перегляд нотаток:** Відображення списку нотаток із можливістю детального перегляду окремого запису.
* **Пошук та фільтрація:** Динамічний пошук нотаток у реальному часі через `SearchBox`.
* **Створення нотаток:** Модальне вікно з формою додавання нових нотаток та валідацією полів.
* **Пагінація:** Зручна навігація по сторінках за допомогою `react-paginate`.
* **Оптимізована робота з даними:** Асинхронне отримання та кешування даних через React Query.
* **Обробка станів:** Налаштовані компоненти завантаження (`loading.tsx`) та помилок (`error.tsx`).

## 🛠 Технологічний стек

* **Фреймворк:** Next.js (App Router)
* **Мова:** TypeScript
* **Стилізація:** CSS Modules, `clsx`
* **Робота з даними та HTTP:** `@tanstack/react-query`, `axios`
* **Форми та валідація:** `formik` / `yup`
* **UI бібліотеки:** `react-paginate`, `react-hot-toast`
